# Angles and Equation Conversion

When solving angle problems with equations, the most important idea is to **convert one equation into another**. Even if two equations do not seem related at first, you can often make them match by adding terms, subtracting terms, splitting terms such as `2B` into `B + B`, or rewriting one part using another known relation. This is usually the key to solving many equation-based problems.

---

## Worked Example

Given:

- `2B + C = 110`
- `A + B + C = 180`
- `F + E + D = 180`
- `A = D`
- `F = C`
- `B = E`

Objective: find `2A + F`.

### Step 1: Convert one equation into another

Start with the given equation:

`2B + C = 110`

Rewrite `2B` as `B + B`:

`B + B + C = 110`

Group the last two terms:

`B + (B + C) = 110`

From the angle sum relation,

`A + B + C = 180`

so,

`B + C = 180 - A`

Substitute into the previous equation:

`B + (180 - A) = 110`

`180 + B - A = 110`

`B - A = -70`

`A - B = 70`

Therefore,

`A = B + 70`

### Step 2: Find `2A + F`

Since `F = C`, we have:

`2A + F = 2A + C`

Now replace `A` with `B + 70`:

`2A + C = 2(B + 70) + C`

`= 2B + 140 + C`

`= 140 + (2B + C)`

Using the given equation `2B + C = 110`:

`2A + F = 140 + 110 = 250`

### Answer

`2A + F = 250`
