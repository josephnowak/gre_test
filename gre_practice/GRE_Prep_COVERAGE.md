# GRE Prep Coverage Used By This UI

This UI was improved after downloading and scanning the GRE prep repository in `../reference/GRE_Prep`.

The PDFs were used only to identify coverage patterns and question-type balance. The app questions in `app.js` should remain independently written.

## Downloaded Reference Set

The local reference copy contains:

- `ETS.pdf`
- `ETS_Quants.pdf`
- `five_lb.pdf`
- `GRE Verbal Strategies - Manhattan Prep.pdf`
- `Kaplan.pdf`
- `Official GRE Verbal Reasoning.pdf`
- `Verbal Workout GRE 6ed ( PDFDrive ).pdf`

Extracted text, for topic analysis only, is stored in `../reference/GRE_Prep_text`.

  - Function/purpose

- Text Completion

## Implementation Rule

Do not paste or lightly paraphrase questions, passages, answer choices, or explanations from the PDFs into `app.js`.

Use the reference set as a topic and difficulty guide, then write original GRE-style questions.
